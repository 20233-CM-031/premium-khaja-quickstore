# ✨ Premium Khaja — Luxury Jewellery QuickStore

A production-grade **SouqOne QuickStore** built for luxury artificial, fashion, and bridal jewellery.

Combining high-converting digital commerce, customer intelligence, AI personal styling, VIP membership club, and seamless WhatsApp ordering.

---

## 🌟 Key Features

- **👑 Royal Luxury Editorial Design**: Tailored luxury aesthetic featuring Cormorant Garamond, Cinzel, and Plus Jakarta Sans typography with warm gold accents.
- **💎 Curated Collections**:
  - Royal Kundan Necklaces & Chokers
  - Jadau Bridal Chooda & Polki Bangles
  - Mughal Chandbalis & Jhumkas
  - Luxury Mathapatti, Maang Tikka & Passa
- **🤖 AI Personal Jewellery Stylist**: Recommends perfect matching pieces based on wedding/reception attire, neckline, color palette, and occasion.
- **🎟️ VIP Privilege Club & Rewards Wallet**: Dynamic membership tiers (Silver, Gold, Royal Diamond), points accumulation, and checkout discounts.
- **📸 Editorial Lookbook**: Shoppable street style and bridal runway lookbooks with instant "Get The Look" quick-add.
- **🛍️ High-Conversion QuickStore Cart**:
  - Live order bump & bundle offers
  - Express WhatsApp Concierge ordering
  - Free insured express delivery countdown
- **⚡ Supercharged Tech Stack**: Built with Vite 5, React 18, Lucide React, and Canvas Confetti for lightning-fast sub-second load times.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/20233-CM-031/premium-khaja-quickstore.git

# Enter project directory
cd premium-khaja-quickstore

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```

## 🌐 Deployment

### Deploy to Netlify
Configured out of the box with `netlify.toml` and SPA redirect rules.
1. Connect your repository to Netlify.
2. Build Command: `npm run build`
3. Publish Directory: `dist`
